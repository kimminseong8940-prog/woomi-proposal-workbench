우미 제안서 워크벤치 — 팀 공유 설정 (한 번만)

■ 되는 것
- 왼쪽「팀 공유」에 올라온 진행 중 프로젝트를 모두가 볼 수 있음
- 클릭해서 열고 이어서 수정한 뒤, 다시「팀에 올리기」가능
- 레퍼런스로 다른 사업장 작업물을 참고 가능

■ 안 되는 것
- 구글문서처럼 글자 단위 실시간 동시편집은 아님
- 같은 프로젝트를 두 사람이 동시에 고치면, 나중에 올린 쪽이 남음
  → 역할 나누거나, 한 사람씩 이어서 수정

■ 팀장 설정 (김민성 PC 권장)
1) GitHub 로그인된 상태에서
   https://github.com/settings/tokens?type=beta
   또는 Classic token 생성
2) 권한: woomi-proposal-workbench 저장소 Contents = Read and write
3) 워크벤치 왼쪽 아래「팀 공유 설정」→ 토큰 붙여넣기 → 저장
4) 프로젝트 작업 후「지금 프로젝트를 팀에 올리기」

■ 팀원
- 주소만 열면 왼쪽「팀 공유」목록이 보임 (팀 새로고침)
- 올리려면 같은 토큰을 설정에 넣거나, 팀장에게 올려 달라고 하면 됨
