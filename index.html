사용 방법 (이렇게만 하시면 됩니다)

처음이시면 이 탭만 읽으시면 됩니다

  1. 왼쪽 목록 진행 중인 프로젝트·팀 공유·샘플이 보입니다. 클릭하면 그 내용이 열립니다. 다른 사람 작업은 「팀 공유」에서 보고, 필요하면 이어서 수정한 뒤 다시 「팀에 올리기」하면 됩니다.
  2. A. 기준선 체크리스트 경쟁사가 기본적으로 넣는 항목을 「포함 / 미포함 / 미정」으로 고르고, 우리 문구를 적습니다.
  3. B. 챕터 골격 제안서 본문에 넣을 내용을 칸에 맞춰 채웁니다.
  4. 요약 · 초안 내보내기 빠진 칸을 확인하고, 워드/PDF 초안을 받습니다.

팀과 같이 쓰려면: 아래쪽 「팀 공유 설정」에서 GitHub 토큰을 한 번 넣어 주세요(팀장 PC). 그다음 누구나 「지금 프로젝트를 팀에 올리기」→ 다른 사람은 왼쪽 「팀 공유」에서 열어 수정 → 다시 올리면 됩니다. 동시에 같은 칸을 두 사람이 고치면, 나중에 올린 쪽이 남습니다.

이 PC에는 자동 저장됩니다. 팀 목록에 보이게 하려면 「팀에 올리기」를 한 번 눌러 주세요.

막히면 「사용방법」 탭을 다시 보시면 됩니다.

팀 공유 설정

팀장이 한 번만 설정하면 됩니다. 토큰이 있는 PC에서 「팀에 올리기」가 됩니다. 목록 보기는 토큰 없이도 됩니다.

GitHub → Settings → Developer settings → Personal access tokens 에서 만듭니다. 권한: 이 저장소 Contents Read and write. 토큰은 이 브라우저에만 저장됩니다.
